## 仓库内的数据结果

每个环境保留40项派生求解结果、40项资格行、40组生产矩阵及40项数值证书。480个NPY文件包括角度、H、G、Q、Q对角元和有序对角和；同时保存160项跨环境DOP配对。所有数据来自既有E16运行，E15分层摘要只作为已有离线实验回执。原始观测文件、星历文件、DLL、Python/NumPy发行物、论文正文及完整研究报告均未加入。

矩阵NPY和选定结果文件按原字节复制；record.json只移除本机绝对路径和运行时路径引用，再增加导出来源说明，数值字段保持原值。`source_provenance.json`区分原文件SHA256与导出文件SHA256。原证书和原记录封存中的record哈希指向原record身份，不能拿它与已脱敏record直接比较；验证程序检查两者的显式对应关系。原封存清单还引用未上传的运行时记录，本包不冒充完整原run。

数据、软件及二进制授权按各自来源处理。此次Private仓库内部协作授权未形成公开再分发许可，不能据此公开原始数据或第三方材料。已保存的模型资格是历史规则的输出；本包可以核对这些标记及有限矩阵算术，不能在缺少原始文件时重新认证完整物理输入。
